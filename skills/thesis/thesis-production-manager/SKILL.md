# Thesis Production Manager

## When To Use

Use when the thesis work needs a practical execution sequence across multiple passes and deliverables.

## Workflow

1. Start with structure audit.
2. Run source hunting for weak evidence.
3. Plan missing figures and tables.
4. Strengthen art/design expression.
5. Check citations.
6. Rewrite AI-sounding prose.
7. Preserve `.docx` formatting during final integration.
8. Finish with a final consistency check.

## Output

- task sequence
- owner-ready checklist
- deliverable list
- risk log
- final verification checklist

## Guardrails

Do not skip verification. Do not claim a pass is finished until the relevant files or text have actually been inspected.

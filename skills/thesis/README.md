# Thesis Skills

Local graduation thesis workflow skills.

## Skills

- `thesis-structure-audit` - structure-first diagnosis before rewriting.
- `academic-source-hunter` - credible academic source hunting and grading.
- `anti-aigc-rewriter` - rewrite formulaic thesis prose without inventing facts.
- `docx-format-preserver` - edit existing Word theses while preserving school formatting.
- `figure-gap-planner` - plan missing figures, tables, diagrams, and evidence visuals.
- `citation-sanity-check` - verify whether citations are real, relevant, and strong enough.
- `art-expression-enhancer` - strengthen design intent, atmosphere, visual language, and artistic discussion.
- `thesis-production-manager` - coordinate multi-pass thesis revision work.

## Routing

Use `thesis-production-manager` for overall sequencing, then route the actual pass to the narrowest skill.

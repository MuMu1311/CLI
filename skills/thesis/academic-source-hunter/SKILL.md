# Academic Source Hunter

## When To Use

Use when claims need stronger citations, weak web references need replacement, or a source list needs sanity grading.

## Workflow

1. Extract claims that require evidence.
2. Prefer CNKI, Wanfang, Google Scholar, arXiv, ACM TOG, IEEE, official Epic/Unreal documentation, ACES documentation, and authoritative standards.
3. Grade sources as core, supporting, background, or not recommended.
4. Match each source to the exact claim it can support.
5. Flag claims that need rewriting because no credible source was found.

## Output

- source shortlist with relevance notes
- replacement list for weak citations
- citation-to-claim mapping
- unsupported claim list

## Guardrails

Do not fabricate titles, authors, DOIs, venues, URLs, or publication years. Browse or inspect supplied files when exact bibliographic accuracy matters.

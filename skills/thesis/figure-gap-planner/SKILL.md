# Figure Gap Planner

## When To Use

Use when a thesis needs stronger visual evidence, clearer technical explanation, or better chapter-level support.

## Workflow

1. Scan each chapter for dense explanation, unsupported process claims, or missing comparisons.
2. Identify visuals already present in source files.
3. Propose missing figures, tables, flowcharts, screenshots, diagrams, or comparison charts.
4. Map each visual to the claim it supports.
5. Prioritize figures that can be produced from existing project assets.

## Output

- chapter-by-chapter figure insertion plan
- figure title suggestions
- visual content requirements
- source asset needs
- claim support notes

## Guardrails

Do not invent nonexistent project screenshots or data. Mark visuals as needed, available, or must be produced.

# Citation Sanity Check

## When To Use

Use before finalizing references or when citations may be fabricated, irrelevant, too weak, or mismatched to claims.

## Workflow

1. Extract citations and the statements they support.
2. Verify existence, bibliographic fields, and source type.
3. Check whether each source actually supports the nearby claim.
4. Flag weak sources, nonacademic sources, duplicated entries, and citation gaps.
5. Produce a cleaned reference action list.

## Output

- verified citation table
- weak or unsupported citation list
- replacement recommendations
- cleaned reference notes

## Guardrails

Do not invent DOIs, URLs, page numbers, journals, or conference names. Use browsing or supplied files for high-stakes bibliographic details.
